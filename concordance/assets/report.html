Do your simulation runs agree?

Add how much each residue moved in each of your repeat runs. You'll see which parts move a lot in every run, which only in some, and what one run alone would have told you. Your files stay on this computer: nothing is uploaded.

    Which files work, and how do I make them?
    • GROMACS: for each run, gmx rmsf -s topol.tpr -f run1.xtc -res -o run1_rmsf.xvg (choose the C-alpha group). Then add all the .xvg files.
    • AMBER: in cpptraj, atomicfluct out run1.dat @CA byres for each run. Then add all the .dat files.
    • A spreadsheet: residue numbers in the first column and one column per run, saved as CSV. A first row of column names is fine, and so is a column of residue names.
    • Anything else: a text file with residue numbers and values in columns. Lines starting with # or @ are ignored.
    • Units only change the numbers shown. Whether a residue “moves a lot” is judged against its own run's typical value, so the answers are the same in nm or Ångström.
    • Every run should cover the same residues, one chain at a time. Three or more runs are best; five is better.

    Same rules as the Concordance command line, which can also start from the simulations themselves. The page gives you the command that reproduces its answer.

              What you are looking at

              Why run a simulation more than once?

              A simulation is a little film of how a protein moves, and every film comes out a bit differently. Guidelines for simulation studies ask for at least three independent runs and for those runs to be compared with each other. Concordance does that comparison for you, residue by residue, and shows its working.

              What this does not tell you

              Agreement between runs is not proof that the answer is right: runs that start from the same structure can agree and still all be wrong. Disagreement, though, is a clear sign that a single run is not enough to support a claim.

              Grossfield et al., LiveCoMS 1, 5067 (2018); Communications Biology 6, 268 (2023) reporting checklist; Knapp, Ospina & Deane, JCTC 14, 6127 (2018).
